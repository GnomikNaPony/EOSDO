# Документы для примера

В этой папке лежат примеры структуры документов, которые можно вручную выбрать при загрузке из своего профиля. Они не импортируются автоматически, не создают записи в реестре и не являются серверным каталогом шаблонов.

- `Служебная записка.md` — пример записки с основанием и сроком.
- `Протокол.md` — пример протокола с решениями и ответственными.
- `Поручение.txt` — пример поручения.

Квадратные скобки обозначают поля для заполнения. Имена, организация и фактические решения не вымышляются. Скопируйте нужный файл, заполните его, создайте документ в своём профиле и загрузите файл во вкладке «Файлы и версии». Автор загрузки берётся из текущей серверной сессии.

PDF/DOCX/XLSX также сохраняются как оригиналы, но извлечение их текста для ИИ пока не подключено. Для проверки текстового сценария используйте эти MD/TXT файлы.
