# 2026-10-29-mobile-demo: мобильное демо ЕОСОД

Статус: завершено.

## Цель и основания

Источник: запрос владельца 29.10.2026, уточнение «Новый демопрофиль при каждом открытии сайта». Телефон, натуральные вымышленные приватные документы, служебная QR-страница, сдержанное обновление компонентов без изменения документооборота. Обычные аккаунты доступны через /login; / открывает новое демо при полной загрузке, внутренняя навигация сохраняет профиль. /demo показывает QR с текущим origin. Публикация не входит в задачу.

Риск повышенный: доступ и приватность. Независимый эталон — явное требование владельца об отдельных приватных профилях; интеграционные проверки взаимного отказа и сохранности обычного входа. Независимое ревью обязательно.

## Область влияния

Полная загрузка клиента → POST auth/demo → транзакция профиля/документов и S3 оригиналы → Redis session cookie → bootstrap → реестр/карточка/скачивание. /login → прежний auth flow. /demo публичен, не запускает профиль. Приватность должна действовать для bootstrap directory/documents, direct document/version download, search/intelligence, templates, notifications, curator views. Ошибка S3/PG не считается успешным демо. Сессия HttpOnly SameSite; client не выбирает owner. Без schema миграции; обычные записи сохраняются. Восстановление: отключить новый клиентский вход и endpoint, не удаляя реальные записи.

## Решение и проверки

Три субагента: мобильный UI; backend/private fixtures; клиентский вход/QR/UI smoke. Общая интеграция и независимое ревью после изменений. Обязательны check, lint, format:check, build, bun test, test:integration, test:ui. Новая QR-зависимость допустима для стандартного сканируемого кода без передачи домена внешнему генератору; точный выбор фиксируется в результате.

## Неопределенность

Факт: исходный код не содержал автоматического демовхода. Владелец явно выбрал новый профиль при каждом открытии. Допущение: полное открытие означает загрузку страницы, а не внутренний переход. Домен берётся из location.origin; деплой отдельно. Неизвестно: требуемый срок хранения демоданных; автоматическое удаление вне текущего запроса, ограничение раскрыть в результате.
