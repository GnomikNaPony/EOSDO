## Ревью

Проход по требованиям: каждое действие сопоставлено с диалогом. Неразборчивый код дела не выдуман. Отдельное новое правило процесса из обсуждения не объявлено утверждённым. Прикладные шаблоны карточек отделены от содержимого файлов и правил ИИ.

Проход по реализации: сервер проверяет типы, допустимые справочники, порядок, целые дни 1–365, максимум 20 этапов/50 шаблонов; допустимые значения проходят в транзакцию. Импорт не переносит владельца, статусы, оригиналы или решения. SQL параметризован, пользовательский текст экранирован; личные шаблоны фильтруются сервером, адресаты не расширяют доступ. Новых зависимостей нет. Изменены только необходимые части существующей архитектуры.

Это два прохода саморевью, **не независимое ревью**. Отдельное независимое ревью не установлено политикой данного локального проекта. Источник ожидаемого поведения — приложенный диалог, а примеры конфликтов/прав/границ проверяются через HTTP и браузер.

## Ограничения и восстановление

- Дела и пользователи демонстрационные. Корпоративный справочник не предоставлен. Выбор роли остаётся намеренно доступным для локальной демонстрации, не заменяет авторизацию.
- Маршрут хранит план очереди, участников и календарные дни. Исполнение этапов, отправка участникам и настоящая ЭП не реализованы; действующее решение остаётся за куратором. Это явно видно в UI и README.
- Импорт JSON версии 1 рассчитан на текущие идентификаторы справочников. Другие/реальные справочники требуют отдельного сопоставления. Импорт создаёт копию, повторный импорт ещё одну.
- Браузер проверен в установленном Chromium, desktop 1440 и mobile 390 px; Safari/Firefox отдельно не проверялись. Поддержка обычных ссылок не требует отдельной библиотеки.
- Старые вкладки нужно перезагрузить: PATCH без profile_revision получает 409. В открытой форме ошибка оставляет текст для копирования; автоматического слияния реквизитов нет.
- До запуска сохранена полная SQLite-копия `data/backups/2026-10-28-before-dialogue.sqlite3`. Добавление таблиц идемпотентно, старые строки не изменены. Для восстановления остановить сервер, сохранить текущую БД отдельно и вернуть копию; новые шаблоны после копии в неё не попадут. Без необходимости откат/удаление данных не выполнялись.

Обязательных непройденных проверок в этих границах нет. Обновлены README и карта проекта. Публикация, промышленная интеграция и изменение правил настоящей ЕОСОД не выполнялись.
