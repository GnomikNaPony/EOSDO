# Исправленная копия презентации

Статус: реализация. Источник: просьба пользователя сделать исправленную копию по результатам шести рецензий. Область: отдельный PPTX, 7 слайдов, корпоративная основа, исходные авторы и достоверные скриншоты. Исходник и приложение не меняются. Риск низкий.

База: redbe66a4fd21dc54c0b42bc13aa1d04016129d7c, в дереве уже присутствует незакоммиченный отчет tasks/2026-10-29-presentation-review/. Контекст и политики прочитаны в этой сессии; требования и доказательства — review.md и geometry.json предыдущей задачи.

AC-01: отдельный открываемый PPTX, семь слайдов, исходник с прежним SHA256.
AC-02: все содержательные объекты внутри холста; восстановлены 6–7, улучшен контраст и снижена перегрузка 2–3.
AC-03: убрано неподтвержденное ускорение; явно разделены скриншоты, иллюстрация и план. Сценарии финала соответствуют основной части; неизвестные параметры пилота не выдуманы.
AC-04: визуальная проверка всех семи слайдов и структурная проверка OOXML; зафиксированы ограничения.

Поток: исходный ZIP/OOXML -> перестройка содержимого с сохранением темы/оригинальных изображений -> новая копия -> Quick Look/Chromium -> визуальная и структурная проверка. Входы: обычный текст, существующие PNG, ошибочные исходные координаты. Риски: выход/переполнение, неверные статусы, потеря связей пакета. Проверки: ZIP CRC, XML parsing, targets relationships, bounds, source hash, семь визуальных копий. Runtime приложения, миграции, конкурентность неприменимы. Новых проектных зависимостей нет; lxml/Pillow/Playwright уже доступны в окружении.

Неизвестны аудитория, длительность, состав/срок/ответственный пилота и версия деплоя. Их не назначаем за владельца; в презентации просим согласовать параметры и показываем эффект как предмет измерения.
