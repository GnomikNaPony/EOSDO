Статус: реализовано, проверка не завершена. Результаты и блокеры — completion.md.

Источник — технические требования владельца от 28.10.2026. База: 2cb8d23b79d3c396a7e9564e49072a1e01aa8ae8, дерево до работы чистое. Риск повышенный: меняются UI, API и хранение. Поток: Solid → HTTP → Fastify validation/authorization → Drizzle PostgreSQL; сессии Redis; файл → S3 → версия PostgreSQL → UI. Ошибки сервисов должны быть видны, не заменяться фиктивными данными.

Матрица: нормальное создание/чтение; пустое имя и неверные типы → 400; отсутствие сессии → отказ; устаревшая редакция → 409; большой файл → отказ; повтор загрузки → без дубликата; конфликт одновременной записи → отказ; недоступные сервисы → ошибка. Старые SQLite-данные не изменяются, автоматический импорт не заявлен. Смешанные вкладки старого UI требуют перезагрузки.

Зависимости: Fastify/Drizzle/Solid/Tailwind прямо требуются владельцем; Vite + Solid plugin нужны для компиляции реактивного JSX; типы Bun нужны checker. Не добавляем pg/redis/aws SDK, formatter или отдельный test runner.

Обязательные проверки: docs/verification.md, ревью требований и реализации. Источники UI и boilerplate закреплены в docs/project.md. Неизвестное: native lint отсутствует в установленном Bun; полная поведенческая эквивалентность и импорт SQLite требуют проверки. До подтверждения всех AC статус не «завершено».
