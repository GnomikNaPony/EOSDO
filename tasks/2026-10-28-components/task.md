# Компоненты и реальные профили

Статус: завершено в согласованном объёме. Результаты — completion.md. Источник: запрос владельца 28.10.2026 о компонентной структуре, Tailwind/ранее выбранном стеке, отсутствии моковых данных и возможности развития решения. Уточнение владельца: templates — просто документы для примера; загрузка выполняется из своих профилей. Автоматический каталог/импорт не требуется.

База — 2cb8d23b79d3c396a7e9564e49072a1e01aa8ae8 и незакоммиченная реализация предыдущих задач; существующие правки сохраняются. Риск повышенный: меняются bootstrap/session/profile. Фиктивные пользователи, дела, правила, организация и seeded документы не поставляются. Реальные старые данные не удаляются; прежняя локальная база сохраняется отдельно, новая рабочая база начинается пустой.

Потоки: профиль → HTTP validation/session → PostgreSQL metadata/Redis session; ручной upload → S3 original → версия PostgreSQL. Папку templates backend не читает. Ошибки не маскируются моками. Test fixtures существуют только в изолированных тестовых базах.

Матрица: пустой workspace → ввод реального профиля/пустые состояния; допустимый файл → версия и текущий автор; неверный тип/размер → отказ; устаревшая версия → конфликт; чужой документ → отказ; недоступный сервис → ошибка. Авторские поля HTTP клиента не определяют владельца загрузки.

Обязательные проверки: lint, check, build, format, реальные интеграционные тесты, UI smoke профиля/create/upload/reload/mobile; два review прохода. Владелец выбрал локальные аккаунты email/пароль. AC-03 также включает регистрацию/вход/выход, password hashing, уникальность email, серверные права, отсутствие автоматического входа и проверки двух реальных аккаунтов. Деплой Railway не выполняется.
