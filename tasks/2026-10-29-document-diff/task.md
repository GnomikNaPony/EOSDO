# 2026-10-29-document-diff: версии, сравнение до/после и замечания

## Цель и основания

По запросу владельца и апруву «Погнали тогда»: линейная git-подобная история неизменяемых файлов, наглядный текстовый diff, замечания к точной версии и история проверки исправлений. Источник ожидаемого поведения — утвержденное предложение в этой сессии. Ветки, слияния, визуальный diff форматирования, OCR, публикация и деплой вне задачи.

Риск повышенный: дополнение API и истории замечаний; правила блокировки согласования сохраняются. Существующие обязательные замечания всех версий продолжают блокировать приемку, пока куратор не закроет их.

## Поток и решение

versions/:id/diff → ACL документа → проверка base той же карточки → извлеченный текст → bounded LCS по строкам → структурированные строки и совместимый diff → диалог Solid. Текст выводится как текст, без HTML. Лимиты длины/строк/числа ячеек предотвращают неограниченный CPU/память; превышение дает явное недоступное сравнение, оригиналы доступны.

Выбор строки → draft с document_id/version_id/anchor → форма замечания → серверная проверка цитаты. Текст и версия исходного замечания не редактируются. Новый comment_event при создании/смене статуса сохраняется в той же PG транзакции, ответы — отдельные записи. Старые замечания без событий показываются без выдуманной истории. Новая версия не закрывает замечания автоматически. Статусы используют существующий latest-version guard и дополнительно ожидаемый статус для обнаружения конфликтов.

Хранение дополняется новым kind в существующем JSONB, без преобразования старых данных. Существующий trigger защищает исходный текст/привязку замечания, ответы и события; миграция обновляет функцию без удаления записей. Legacy версии без parent_id сравниваются с ближайшей предыдущей по номеру. Откат приложения оставляет новые записи неиспользуемыми; оригиналы/замечания не перезаписываются. Зависимостей нет.

## Матрица сценариев

| Категория | Пример и ожидаемый результат |
|---|---|
| Нормальные | A/B/C → A/D/C: B удалено, D добавлено, A/C общий контекст |
| Пустые | первая версия, пустой извлеченный текст: явное состояние/корректная вставка |
| Граничные | одинаковый текст, CRLF, завершающий перевод строки, повторяющиеся строки |
| Некорректные | base чужой карточки, несуществующий id, неверный статус/цитата: отказ |
| Большие | >500000 символов, >10000 строк или >4 млн ячеек: явный лимит, без частичного ложного diff |
| Повторы | одинаковый файл и устаревший parent_id: существующий 409 |
| Конкурентность | устаревшая версия/ожидаемый статус: 409; смена карточки во время diff не открывает чужой результат |
| Отказ | ошибка API видима, история и файл не подменяются успехом; записи событий атомарны |
| Старые данные | комментарий без событий доступен; прежний клиент получает поле diff |
